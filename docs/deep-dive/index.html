深度实现文档（Deep Dive）

本套文档是 docs/html/ 流程文档站的补充：聚焦每个技术点怎么实现、为什么这样实现，所有步骤均给出真实示例输入 / 输出（示例数据取自本仓库 data/processed/、artifacts/ 中的实际产物），关键参数与源码文件一一对应，可对照 src/insurwiki_rag/ 逐行核验。

阅读前提：先读 docs/html/index.html 了解项目全貌，再用本套文档下钻。两套文档互不替代：流程站回答"是什么、走哪条路"，本站回答"怎么做的、数据长什么样"。

环节技术实现位置为什么不用别的

复现环境速查

# 一条命令跑通：拉取→清洗→切分→索引→图谱→Wiki（首次约需下载 3 万条数据 + 2 个本地模型）
.venv/bin/python scripts/pipeline.py

# 只重建索引/图谱/Wiki（复用已处理数据）
.venv/bin/python scripts/pipeline.py --skip-data

# 起服务（默认 8010，工作台 / 流程文档 / 本文档站）
.venv/bin/python -m uvicorn insurwiki_rag.server.main:app --port 8010 --app-dir src

# 评测
.venv/bin/python scripts/evaluate.py --n 60        # Hit@5 + 支撑率 + 拒答率
.venv/bin/python -m pytest tests/ -q
关键配置（src/insurwiki_rag/config.py，均可由 .env 覆盖）： RRF_K=60 · RERANK_TOP_N=5 · SUPPORT_THRESHOLD=0.35（拒答阈值） · DATA_SAMPLE=1500 · 切分 MAX_CHARS=420 / OVERLAP_CHARS=60 · LLM_MODEL=glm-5.3 降级 glm-4.6。
