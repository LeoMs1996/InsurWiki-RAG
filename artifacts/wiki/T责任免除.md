# 责任免除（免责条款）

## 主题概述
责任免除条款规定了保险人不承担给付保险金责任的情形，涵盖投保人故意杀害伤害、被保险人故意犯罪、吸毒、酒后驾驶、无证驾驶等，导致重大疾病及轻症疾病保险金责任被免除。

## 核心条款要点
- 投保人对被保险人的故意杀害、故意伤害，保险人不承担给付保险金责任 [泰康E款团体重大疾病保险 2.5 / 泰康建筑工程人员团体意外伤害保险 2.4]
- 被保险人故意犯罪或抗拒依法采取的刑事强制措施导致保险事故的，责任免除 [泰康E款团体重大疾病保险 2.5 / 泰康医养宝社保补充团体医疗保险A款 2.5]
- 被保险人主动吸食或注射毒品的，保险人不予给付 [泰康E款团体重大疾病保险 2.5 / 泰康医养宝社保补充团体医疗保险A款 2.5]
- 被保险人酒后驾驶、无合法有效驾驶证驾驶或驾驶无有效行驶证机动车的，责任免除 [泰康建筑工程人员团体意外伤害保险 2.4]
- 上述免责情形导致初次确诊重大疾病或轻症疾病的，保险人不承担给付重大疾病保险金或轻症疾病保险金的责任 [泰康E款团体重大疾病保险 2.5]
- 因第（1）项情形确诊重大疾病的，合同对该被保险人责任终止，仅给付现金价值 [泰康E款团体重大疾病保险 2.5]

## 常见问答
**Q：如果是投保人故意杀害或故意伤害被保险人，保险公司会承担责任吗？**

A：不承担。根据材料第2.5条第(1)项，投保人故意杀害或故意伤害被保险人，保险公司不承担重大疾病保险金的责任。

**Q：保险公司在哪些情况下不承担赔偿责任？**

A：保险公司在以下六种情况下不承担赔偿责任：
* **专有名词解释：**
    * **故意杀害、故意伤害：**蓄意或故意的对他人造成伤害的行为。
    * **故意自伤：**故意对自己造成伤害的行为。
    * **抗拒依法采取的刑事强制措施：**对执法人员执行逮捕、拘留等法律措施时的反抗行为。
    * **毒品：**能使人产生幻觉、兴奋、嗜睡或其他精神症状，容易上瘾的物质。

**Q：如果被保险人在保险合同终止后身故，保险公司会承担保险责任吗？**

A：**专有名词解释：**
* **保险合同终止：**指保险合同因各种原因而结束效力。

保险合同终止、撤销、解除或效力中止期间内，保险公司不再承担保险责任。因此，如果被保险人在上述期间身故，保险公司将不承担给付身故保险金的责任。
